About Agro-Ware

Agro-Ware is a standalone, hardware‑integrated recoil compensation system designed for Rust, using a Raspberry Pi Pico to act as a real USB mouse so that its input is not detectable by Easy Anti‑Cheat.

The script features a modern Dear PyGui interface with a dark theme, weapon profiles (AK‑47, LR‑300, MP5, Custom), sensitivity matching for General and ADS, a real‑time recoil pattern visualizer, and humanization to add random variance for a more natural feel.

Time‑limited, HWID‑bound license system F1: Toggle F2: Cycle weapons F3: Emergency stop F4: Humanization Arrow keys: Adjust strength

It includes a time‑limited, HWID‑bound license system that binds keys to the first PC that activates them, and offers hotkeys (F1 to toggle, F2 to cycle weapons, F3 for emergency stop, F4 for humanization, and arrow keys to adjust strength).
